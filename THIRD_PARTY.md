# Third-party game sources

## Mechanics (source of truth)

**[THEN00P/reFlappy](https://github.com/THEN00P/reFlappy)** — deobfuscation / recompilation of the original Android Flappy Bird (`com.dotgears.flappy` by Dong Nguyen / .GEARS).

Our C simulator copies the gameplay constants from:

| File | What we take |
| --- | --- |
| `Bird.java` | gravity `0.3`, flap velocity `-5`, max fall `8`, start `(80,246)`, collision `20×20` |
| `GameScene.java` | scroll `2`, gap `96`, pipe height `randomRange(180,360)`, screen `288×512`, ground line `400` |
| `atlas.txt` | `pipe_up`/`pipe_down` `52×320`, land `336×112` |

Original game © Dong Nguyen / .GEARS. reFlappy is used here as a research reference for measurements only.

## Look (sprites / HTML play UI)

**[nebez/floppybird](https://github.com/nebez/floppybird)** — HTML5 clone using sprites extracted from the original Android game.

Vendored under `vendor/floppybird/` (pipes, land, sky). Our `play/` page loads those environment assets but drives **reFlappy physics**.

**Player sprite:** custom Flappy-style fruit-fly frames in `play/assets/fly/` (generated by `scripts/make_fly_sprites.py`). AI concept refs were used as style guidance; in-game frames are discrete 34×24 PNGs with a `0-1-2-1` flap cycle (not a scrolling sheet).

Dong Nguyen’s public comments have been treated by floppybird’s author as permission to reuse the concept/assets in open non-commercial projects. If the copyright holder requests removal, delete `vendor/floppybird/assets` and open an issue.

## Not used as physics truth

- Generic tutorial clones (different gravity / gaps)
- `sourabhv/FlapPyBird` (popular RL wrapper; different tuned constants)
